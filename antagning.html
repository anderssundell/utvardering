Noter och definitioner

Begrepp Förklaring
BI Gymnasiebetyg utan komplettering (betyg direkt från gymnasiet, max 22.5)
BII Gymnasiebetyg med komplettering (tillagda poäng via t.ex. naturvetenskapliga ämnen)
HP Högskoleprov, skala 0.0–2.0
AU Akademiska meriter – används för masterprogram. Betyg på kandidatexamen och relevant erfarenhet bedöms av institutionen.
DA Direktantagning – reserverade platser för stipendiater eller avtalsstudenter
Alla behöriga Innebär att alla behöriga sökande erbjöds plats (inte fullt konkurrensurval). Markeras "999" i UHR-API:et, "*" i UI.
Urval 1 / Urval 2 Urval 1 = preliminärt, Urval 2 = slutligt urval (efter tacksägelse). Antagningspoäng avser urval 2 för S1STV, urval 1 för masterprogrammen.
Sökande totalt Alla sökande oavsett preferensordning, vid sista anmälningsdag
Förstahandssökande Sökande som angett programmet som förstahandsval

All statistik hämtad från UHR Antagningsstatistik via internt API (februari 2026). Antagningspoäng för S1STV kompletterade med data från Antagningsportalen.se. Masterprogram (S2PSC, S2IAG) antas via universityadmissions.se.
